## Replacing a screen

1. Check the new image against "Cleaning before anything goes in" in
   `../README.md`. This repository is public.
2. Export the screen from Figma as a PNG at 1x.
3. Give it the same file name as the image it replaces, so its history stays
   in one file. A new screen gets a new lowercase name with hyphens, and a row
   in the table above.
4. Put it on a branch and open a pull request. On github.com you can do this
   without any tools: open this folder, choose "Add file", then "Upload
   files", and pick "Create a new branch" before you commit.
